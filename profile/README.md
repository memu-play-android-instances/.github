## Troubleshooting Common Issues

Install issues? Enable virtualisation in firmware when an instance fails to start.  
Performance problems? Lower per-instance memory when the host becomes unstable.  
License/activation? Switch the renderer if graphics show artefacts.  
Compatibility? Restore a snapshot instead of repairing a corrupted instance.  
Update failures? Check free disk space before creating another instance.
